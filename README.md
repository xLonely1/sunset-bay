Sunset Bay — a 2D top-down open-world crime game in the spirit of GTA 6: steal cars, run jobs for Rico and Lena, dodge the Sunset Bay PD, and take the gold Aurora from the Grand Bay Casino. An original city, story and cast; no assets from any commercial game.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files under `game/`.

## How to play

- **WASD / Arrows** — walk and drive · **Shift** — sprint
- **E** — steal a car / get out · **Space** — punch · **F / Click** — shoot (once Lena lends you her pistol)
- **P** — pause · **M** — mute

Four story missions from Rico and Lena: First Wheels, Harbor Run, Pier Brawl, and The Aurora Job. Wanted stars bring the police — on foot they bust you, in cars they ram you. Progress saves in your browser.
